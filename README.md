# Animal Mayhem (2D prototype)

Flutter and Flame project for **Animal Mayhem**, a playable 2D animal puzzle
game.

The application lives in [`animal_mayhem/`](animal_mayhem/). It is a **10-stage
gameplay prototype** covering the completed initial Stage 1–10 roadmap (not ten
separately packaged commercial levels).
